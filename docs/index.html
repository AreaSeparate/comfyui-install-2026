Install

  1. Open Releases and download the Windows pack
  2. Extract with 7-Zip to a path without Cyrillic or spaces (example C:\ComfyUI)
  3. Run the GPU bat that matches your card (NVIDIA / AMD / Intel / CPU)
  4. When the browser UI opens, drop a .safetensors checkpoint into models/checkpoints
  5. Type a prompt and press Queue Prompt

How to tell it worked

Success = browser UI + a test prompt that finishes. Red node errors usually mean a missing model, not a broken exe.

FAQ

Do I need Python?

No. comfyui-install-2026 is a portable Windows pack. Extract and run the .bat for your GPU.

Where do models go?

Put .safetensors checkpoints in models/checkpoints. LoRAs and VAEs have their own folders. Missing files show as red nodes.

NVIDIA or AMD?

NVIDIA: run_nvidia_gpu.bat (6 GB+ VRAM recommended). AMD: DirectML/ROCm launcher. CPU works but is slow.

Is this the official ComfyUI?

The engine is the open-source project https://github.com/Comfy-Org/ComfyUI. This page is the Windows pack named comfyui-install-2026.
